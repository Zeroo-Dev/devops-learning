# AGENTS.md

Personal DevOps learning/notes repo (Russian-language README). No application code, no build, test, lint, or package tooling — don't hunt for it.

## Layout
- Topic dirs are numbered `00-notes` … `10-final-project`; files go inside the matching topic.
- These dirs are empty placeholders. Git does not track empty dirs, so `git ls-files` shows only `README.md` until a file is added inside one.

## Conventions
- Write notes as Markdown files inside the relevant numbered dir (e.g. `06-k8s/notes.md`).
- `README.md` and commit messages are in Russian; match that language for notes.
- Single branch `main`; remote `origin` = git@github.com:Zeroo-Dev/devops-learning.git.
- Don't commit unless asked.
